# Movie Watchlist Manager (MERN Stack)

A full-stack MERN application for managing a personal movie watchlist with custom status workflows, automated code generation, and aggregation statistics.

## Project Structure
- backend: Node.js & Express API with MongoDB Atlas
- frontend: React application (Vite)

## Setup Instructions
1. Backend:
   cd backend
   npm install
   node server.js
2. Frontend:
   cd frontend
   npm install
   npm run dev
